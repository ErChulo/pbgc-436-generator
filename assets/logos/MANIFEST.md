# Logos

Official PBGC logos, copied from the Book of Job (Drive folder
"images", 31 logo files found). Source copies only; the HTML embeds
the white (wt) logo as base64.

| File | Source | Use |
| --- | --- | --- |
| `PBGC_logo_name_hor_wt.png` | Book of Job images | White logo, embedded in the blue header, both themes. |
| `PBGC_logo_name_hor_fc.png` | Book of Job images | Full colour logo, source only, not in the app. |

The wt PNG is byte-identical to the copy used in the DEL generator
(sha256 verified). The HTML carries the wt logo embedded; the logo
PNGs are NOT separate files on GitHub (snapshot push is UTF-8 text
only).
